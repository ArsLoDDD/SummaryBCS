# План розвитку SummaryBCS

## Поточний етап

Три окремі прості режими використовують одну модель даних і один Excel-формат:

1. **Зведення БЧС** — об'єднання готових файлів.
2. **Шаблон БЧС** — опис структури та створення порожнього XLSX потрібного розміру.
3. **Редактор БЧС** — створення структури, заповнення людей у програмі та експорт XLSX.

Правила підрахунку БЧС затверджені: службові порожні рядки не враховуються, зовнішні категорії рахуються окремо, а «В наявності» охоплює лише власний склад поза переліком відсутніх станів.

## Етап 2 — аналітика за попередню добу

Користувач обирає два БЧС: за попередній і поточний день. Програма локально показує:

- зміну «по штату», «по списку» та «в наявності»;
- доданих і вибулих людей;
- зміни місця перебування;
- переведення між блоками або екіпажами;
- зміни статусу та типу екіпажу;
- незаповнені обов'язкові поля, дублікати та невідомі значення.

Для надійного зіставлення редактор має зберігати прихований стабільний ідентифікатор людини. Для старих файлів без ідентифікатора використовується нормалізоване П.І.Б.; неоднозначні збіги програма не вгадує, а показує для перевірки.

## Етап 3 — аналітика за місяць

Користувач обирає всі денні БЧС за місяць. Програма:

- сортує файли за датами;
- знаходить пропущені або повторні дні;
- будує динаміку «по штату / по списку / в наявності»;
- показує зміну кількості екіпажів за статусами й типами БпАК;
- показує тривалі та повторні відсутності;
- знаходить часті зміни місця перебування;
- показує систематично незаповнені поля й помилки довідників;
- експортує короткий звіт без зміни вихідних файлів.

Автоматичні висновки називаються **сигналами для перевірки**, а не підтвердженими проблемами.

## Безпека й масштаб

- Уся обробка виконується локально на комп'ютері.
- Формули з вхідних Excel-файлів не виконуються.
- Макроси не приймаються.
- Вихідні файли не перезаписуються без явного вибору користувача.
- Цільова перевірка продуктивності: не менше 10 000 рядків людей і кілька сотень екіпажів.

## Обов'язкові перевірки перед випуском

- усі типи структури та відсутність управління;
- екіпажі різного розміру, включно з нулем;
- правила списків і кольорів;
- перенесення всіх довгих назв усередині комірок без виходу тексту за рамки;
- формули на першому й останньому рядках;
- сумісність зі старим XLSX без службових ідентифікаторів;
- коректне порівняння доби та місяця;
- три незалежні Windows-збірки.
